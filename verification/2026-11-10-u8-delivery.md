### 3.1 新增来源（真实请求）

```http
POST /orchestrator/api/sources
x-orchestrator-request: 1
{"kind":"github","id":"u8-check","config":{"repository":"u8-check/probe","cli":"gh","instanceUrl":""}}
```

响应 `200`：

```json
{"id":"u8-check","revision":5,"restarting":true}
```

随后轮询到运行态：`GET settings` 中 `u8-check` 的 `installed: true`、`enabled: true`，`config` 被补全为 `pollSeconds: 60`、`failuresBeforeError: 3` 与四个 `observe*` 开关；`GET sources` 中该记录 `state: error`，`problem.code = agentCliMissing`，`detail = "The agent GitHub CLI was not found.\ngh is not an executable file on PATH"`。

该 `problem` 是本机环境事实（桌面进程的 `PATH` 中没有 `gh`），不是新增失败：记录已持久化、已注册到运行态、已出现在设置与状态接口中。原始响应见 [create.json](2026-11-10-u8-delivery/create.json)、[settings-after-create.json](2026-11-10-u8-delivery/settings-after-create.json)、[sources-after-create.json](2026-11-10-u8-delivery/sources-after-create.json)。
